- Instalación librería de componentes UI shedcn-ui para Vite: ver apuntes/instalar-shadcn-ui.txt
 
	- https://ui.shadcn.com/docs/installation/vite#existing-project
	- Incluye la instalación de tailwindcss: npm install tailwindcss @tailwindcss/vite
	- Incluye la instalación de: npm install -D @types/node
	- Agregar al index.css: @import "tailwindcss";
	- tsconfig.json agregar:
		"compilerOptions": {
			"baseUrl": ".",
 			"paths": {
				"@/*": ["./src/*"]
   			}
  		}

	- tsconfig.app.json, dentro de "CompilerOptions" { },  agregar:
		    "baseUrl": ".",
		    "paths": {
		        "@/*": [
		           "./src/*"
		        ]
		    }

	/----- ⚠️ ----/	
	Solución al posible fallo de baseUrl en tsconfig.json:
	1. tsconfig.json
	Eliminar "baseUrl": ".". El path "@/*": ["./src/*"] ya resuelve correctamente relativo al directorio del tsconfig.
	2. tsconfig.app.json
	- Eliminar "baseUrl": "./src"
	- Agregar "@/*": ["./src/*"] para que TypeScript resuelva las importaciones de shadcn/ui 
	  (este mapping faltaba, pero el error de baseUrl ocultaba este problema)
	- Mantener "*": ["./src/*"] para imports como 05-useReducer/TaskApp
	/-----------/

	- En un terminal del proyecto:	npm install -D @types/node

	- vite.config.ts agregar:
		import path from "path"
		import tailwindcss from "@tailwindcss/vite"

		// https://vite.dev/config/
		export default defineConfig({
  			plugins: [
			    react(),
			    tailwindcss(),
			    babel({ presets: [reactCompilerPreset()] })
			],
			resolve: {	
		    		alias: {
		      			"@": path.resolve(__dirname, "./src"),
		    		},
  			},
		});

	- Run the CLI#: npx shadcn@latest init
		- Need to install the following packages: shadcn@4.12.0 >> Yes
		- 🚨Select a component library » Radix
		- ? Which preset would you like to use? » Nova (estilo visual más moderno)
	

	- Crear un botón de ejmplo: npx shadcn@latest add button
 	  Esto genera el código del botón en: src/components/ui/button.tsx

	- Insertar el botón en el código:
		import { Button } from './components/ui/button'
		<Button>Ejemplo Botón</Button>

	- Para que el botón muestre el puntero: abrir src/components/ui/button.tsx y agregar cursor-pointer
